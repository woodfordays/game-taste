Context: `status` (a ResearchStatus: the `run` to show, whether it is `active`, its last `events`, the lanes still `short`, its `summary`, its `key` and the `current_round`) and `result_labels` (the word for each run status). Nothing active: the Run research button, which opens the start dialog in #dialog, and how the last run went. The root listens for the `research-started` event (sent when the dialog starts a run) and loads the status again, saying it was waiting on a run (`was=running`) so that a run which is already over by then still sends `research-finished`. Running: a moving progress bar that says what the newest log line says, the log, and Cancel research. A cancel already asked for shows as a disabled "Cancelling". Paused: where it stopped, the lanes still short, and the three choices, with one more round the only primary button.
