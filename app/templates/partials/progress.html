{#- Ember's Progress, as its React reference draws it: the visible label names the track, which is the `progressbar`. With `value` (of `max`) the bar fills; without it the bar moves to show that something is happening. `value_text` is the readout at the end of the label row and the bar's spoken value ("1 of 3"). `id` must be unique on the page: the label's id is made from it. -#} {% macro progress_bar(id, label, value=none, max=100, value_text=none) -%} {%- set moving = value is none %}
{{ label }} {%- if value_text %} {{ value_text }} {%- endif %}
{%- endmacro %} {#- A note with a moving bar while an htmx request is out. It is hidden until htmx adds `htmx-request` to it (when a trigger names it in `hx-indicator`) or to an element around it, such as the form that sent the request. -#} {% macro busy_note(id, label) -%}
{{ progress_bar(id ~ "-bar", label) }}
{%- endmacro %}
