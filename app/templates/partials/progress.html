{#- Ember's progress bar. With `done` and a nonzero `total` it fills to done of total and says so ("2 of 5"); without them it is the moving bar that only says something is happening. The label is visible text and the bar's accessible name. -#} {% macro progress_bar(label, done=none, total=none) -%} {%- set filled = done is not none and total %}
{{ label }} {%- if filled %} {{ done }} of {{ total }} {%- endif %}
{%- endmacro %} {#- A note that shows a moving bar while an htmx request is out. It is hidden until htmx adds `htmx-request` to it (when a trigger names it in `hx-indicator`) or to the form it sits in. `id` and `class` let a page place it. -#} {% macro busy_note(label, id=none, class="") -%} {{ progress_bar(label) }} {%- endmacro %}
